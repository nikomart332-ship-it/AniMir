# AniMir — мобильный PWA-каталог аниме

## Запуск
Для проверки откройте `index.html`. Для установки как PWA и работы service worker разместите файлы на HTTPS-хостинге (или используйте localhost при разработке).

## Состав
- `index.html` — интерфейс, каталог Jikan API v4, поиск, фильтры, избранное и история.
- `manifest.webmanifest` — настройки установки на главный экран.
- `sw.js` — кеширование оболочки сайта для повторного открытия без сети.
- `icon.svg` — иконка AniMir.

## Публикация
Загрузите все четыре файла в корень статического HTTPS-хостинга. Затем откройте адрес сайта на Android в Chrome и выберите «Установить приложение» / «Добавить на главный экран». На iPhone используйте «Поделиться» → «На экран Домой».

## Ограничения
Jikan API предоставляет метаданные и постеры, но не видео серий. Плеер остаётся заглушкой до подключения видео, на распространение которых есть разрешение. Бесплатный доступ без рекламы возможен, но права на контент и стоимость его хостинга нужно учитывать отдельно.
